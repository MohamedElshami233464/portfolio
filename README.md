## 📁 Projects Overview

| Project | Description | Tech | Folder |

| **1. SDG 1 – Female Poverty Dashboard** | Power BI dashboard analyzing female poverty rates across global regions using UN SDG data. Includes EDA, data cleaning, and regression-based insights. | Power BI, Python | [📂 Folder](./sdg1-female-poverty-dashboard) |
| **2. NAC Breda Player Analytics** | Data science project with NAC Breda Football Club exploring market value, player performance, and contracts using regression and clustering. | Python, scikit-learn, EDA, Feature Engineering | [📂 Folder](./NAC-breda-player-analytics) |
